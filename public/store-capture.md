# Capturing App Store screenshots

1. Run `npx expo start --web` and open http://localhost:8081/store.html in Chrome.
2. Press `1` to switch the frames to full size (1290 × 2796, the iPhone 6.7" size Apple requires).
3. In DevTools, right-click each `section.frame` and choose "Capture node screenshot".
4. Press `0` to return to the review scale.

Replace the iframe `src` values once real preview pairs and a real processing result exist. Headlines follow the
category convention: short, uppercase, one promise per frame.
